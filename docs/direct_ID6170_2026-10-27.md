# ID6170: first direct R+C profile fits

These notes describe the initial profile-only pilots. The current
`direct_source_fit.ipynb` has since gained joint emission-map/kinematic MCMC;
see [the MCMC implementation notes](direct_joint_mcmc_2026-10-27.md). The
profile pilot results below have not been replaced or reinterpreted as MCMC.
The original notebooks and prior runs remain available.

## Settings and interpretation

- Source center fixed at (40.25, 41.0) zero-based source-frame pixels.
- Inclination fitted under a Gaussian prior of 75 +/- 5 degrees, bounded 5–85.
- Other fitted parameters: V_inf, turnover radius, cutout PA, R dx and R dy.
- V_inf bounded 0–1000 km/s; turnover radius 0.5–40 pixels; offsets +/-10 pixels.
- One independent nonnegative brightness per source pixel, shared between R+C.
  No Sérsic shape, smoothing penalty or imaging-derived emission template.
- Original R/C pixels compared with direct forward predictions; no data rectification.
- Separate input noise estimates: R=0.00341413, C=0.00351514. Coadd covariance is
  not modeled. Only nonfinite input pixels are excluded; all current pixels are finite.
- C registration and systemic velocity fixed at zero. No explicit PSF or intrinsic
  velocity dispersion in this initial experiment. Imaging is display-only.

These are local profile fits with an inclination penalty. They are not MCMC runs,
and profiling the brightness map does not marginalize its uncertainty. No
posterior error bars, corner plot or mass errors are produced.

## Executed pilots

Both pilots used initial turnover radius 10.09 pixels, PA=286.64 degrees,
R offsets=(1.0625, 0.2852), inclination=75 degrees, and a 150-evaluation budget.
Only the starting velocity differed. Both ran on CPU.

| Quantity | Start 450 km/s | Start 250 km/s |
|---|---:|---:|
| Fitted V_inf [km/s] | 461.38 | 321.76 |
| Turnover radius [pixel] | 10.364 | 7.239 |
| Inclination [degree] | 70.13 | 71.79 |

| V(5 pixels) [km/s] | 132.03 | 123.82 |

| Data chi squared | 13246.71 | 13217.68 |
| Inclination negative-log-prior penalty | 0.4744 | 0.2062 |
| Total score, chi squared / 2 + penalty | 6623.830 | 6609.047 |
| Evaluations | 102 | 85 |
| Total execution time [seconds] | 68.7 | 51.8 |

The second solution has the lower score under this experimental objective.
The asymptotic speeds are not stable across starts. The values at a common inner
radius agree more closely, but this is not a posterior interval or a measurement
of which radii are constrained. Do not compare the two values of V(R_t) as if
they referred to the same physical radius.

Both optimizers stopped on small relative score changes, and both failed the
strict projected-gradient criterion. The maximum scaled gradients were about
8.79 and 81.58. These are best local points found, not certified global optima.
The inner nonnegative solves completed with optimalities about 5.98e-8 and
4.79e-8. Saved records expose these distinctions.

## Data features requiring inspection

The prior artifact replacement is present in C: 131 pixels in the user-defined
circle were replaced with a background median. Three strong negative pixels
remain outside that circle, at zero-based (x,y) positions:

| Position | Input value | Approximate noise standard deviations |
|---|---:|---:|
| (46,61) | -0.12904 | -36.7 |
| (40,55) | -0.08697 | -24.7 |
| (35,49) | -0.08080 | -23.0 |

All remain in the fit. A nonnegative emission model cannot explain their negative
flux, so they contribute at least approximately 2490 to chi squared. The nearest
one is close enough to the galaxy to warrant visual inspection. No input files
were edited during these pilots. The residual display saturates at +/-5 and
prints the number of pixels beyond that range; clipping affects only the plot.
